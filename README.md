# Lab3 - Include--Formularios-HTML5
 
Repositorio para la entrega del Laboratorio: Include--Formularios-HTML5 Creado y desarrollado por Dylan Pitti del salón 1S3122
 
 
Es un laboratorio enfocado en los fundamentos de HTML5 tanto del backend y front end, también incluyendo carpetas y subida de archivos.
## Contenidos del Repositorio
 
| Archivo | Descripción |
|---|---|
| `index.php` | Página principal con el formulario visual de registro |
| `procesar.php` | Página de backend que valida, procesa y muestra el resultado |
| `includes/` |  Ejercicio para continuar con la práctica de tablas sencillas en HTML.|
| `header.php` | Contiene el <header>, Navbar y Breadcrumb dinámico |
| `footer.php` | Contiene el <footer> con enlaces y año dinámico|
| `uploaded_files/` | Carpeta donde se guardarán las fotos subidas con permisos de escritura |
| `.gitkeep` | Archivo oculto opcional para que Git mantenga la carpeta vacía |




 
## Lenguajes Utilizados
 
- **PHP** 

##  Cómo ejecutar el proyecto
 
1. Clonar el repositorio:
```bash
   git clone https://github.com/dylan-pitti/Include---Formularios-HTML5.git
```
2. Colocarlo dentro del directorio de tu servidor local (www si se usa WAMP o LAMP).
3. Iniciar Wamp o Lamp después conectarse al servidor local mediante hhtp://127.1.1.1
4. Elegir el archivo a probar dentro de la carpeta asignada (el index.php)
